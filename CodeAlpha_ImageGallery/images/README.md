# CodeAlpha Image Gallery

## About the Project
A responsive image gallery built using HTML, CSS, and JavaScript.

## Features
- Responsive gallery layout
- Image filtering
- Lightbox image preview
- Next and previous image navigation
- Keyboard navigation
- Touch swipe support

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open `index.html` in your browser, or use the Live Server extension.
3. Explore the image gallery and its features.

## Project Structure
- `index.html` — HTML structure
- `style.css` — Styling and responsive layout
- `script.js` — Gallery functionality
- `README.md` — Project documentation
